Tutorial de como iniciar um projeto em angular:

  1. Instalar a extensão do VS Code

    Vá até a aba de extensões do VS Code e instale a extensão "Angular Language Service".

  2. Ativar o Auto Save

    No menu File do VS Code, ative a opção Auto Save, para não precisar salvar manualmente toda hora(salva vidas).

  3. Escolher uma pasta para o projeto

    Crie ou selecione a pasta onde o projeto vai ficar hospedado no seu computador

  4. Abrir o terminal

    Abra o terminal do VS Code. Vá no icone + para incializar o CMD

  5. Instalar o Angular CLI

    Digite o comando abaixo para instalar o Angular globalmente na sua máquina:

    npm i -g @angular/cli

  6. Verificar a instalação

    Confirme se o Angular foi instalado corretamente:

    npx ng --version

  7. Criar o projeto

    Para criar o site, Digite no CMD:

    npx ng new nomedoapp --directory .

    Obs: se não funcionar, tente sem o ponto no final:

    npx ng new nomedoapp --directory

  8. Rodar o projeto

    Para subir o site, digite:

    npm start

  9. Caso dê problema ao rodar site:

    Para reiniciar o servidor do site é só digitar no terminal:

    ctrl + c

    Ao fazer isto o servidor do site reinciará.
